## Основные проекты

### [AI Document Review Pipeline](https://github.com/OlegonZo/ai-document-review-pipeline)

Python · FastAPI · SQLite · n8n · unittest

- HTTP webhook принимает текст документа с валидацией входных полей.
- Классификатор отделён от бизнес-правил: достаточность данных определяет статус `ready` или `review` с причинами решения.
- Документ и событие журнала сохраняются в одной транзакции SQLite; доступна выборка по статусу.
- Есть импортируемый пример n8n: webhook → HTTP API → проверка статуса.
- Границы: локальная демонстрация на синтетических данных, классификатор без внешнего LLM; без интеграции с 1С, GetCourse и Telegram. Уведомления и защищённый от изменения журнал не реализованы.

### [BotOps Control Center](https://github.com/OlegonZo/botops-control-center)

TypeScript · React · серверный API · GitHub Actions

- Развёрнутый интерфейс наблюдения за исследовательскими процессами: состояния, контекст инцидентов и инструкции восстановления.
- Серверные health- и brief-эндпоинты, проверка входных данных и обработка ошибок.
- Опциональная серверная ветка OpenAI Responses API; без ключа возвращается детерминированная demo-сводка.
- Телеметрия помечена как демонстрационная. Интерфейс не подключается к биржам и не подтверждает прибыльность стратегий.

### [Exchange Monitoring Lab](https://github.com/OlegonZo/exchange-monitoring-lab)

Python · dataclasses · Decimal · unittest · GitHub Actions

- Нормализация синтетических MEXC/Hyperliquid payloads в общую модель данных.
- Расчёты на Decimal, детерминированные состояния исследовательского paper-процесса, форматирование сообщений.
- Воспроизводимый CLI-пример, тесты и CI для Python 3.11–3.13.
- Публичный пакет не авторизуется на биржах, не размещает ордера и не отправляет сообщения в Telegram.
